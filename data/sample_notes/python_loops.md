# Python Loops and Iteration

Loops execute a code block multiple times until a condition terminates.

## While Loops
Executes as long as the condition evaluates to True:
count = 0
while count < 5:
    print(count)
    count += 1

## For Loops and Range
Iterates across collections or range generators:
for i in range(1, 6):
    print(i)

## Control Statements
- break: Terminate loop immediately.
- continue: Skip remainder of current iteration and jump to next step in the loop. Continue statement.
- else with loops: Runs only when loop finishes normally without encountering break.
